# Python 设计模式修炼手册

> **一本通俗、有趣、可运行的 Python 设计模式书**
>
> 覆盖全部 23 个 GoF 经典设计模式 + 1 个"编外"高频模式（简单工厂），共 **24 个模式**。
> 每个章节的每一段代码都经过**实际运行验证**，保证准确无误。

---

## 这本书有什么不一样？

- 🐍 **为 Python 量身定制**：不照搬 Java/C++ 的写法，每个模式都讲清楚"在 Python 里应该怎么写"，以及"Python 的哪些特性让这个模式变简单甚至消失了"。
- 📊 **按使用率排序**：先学天天用的（单例、策略、装饰器……），再学偶尔用的（备忘录、享元……），最后是压箱底的（解释器）。排序依据：**实际开发使用率为主，难易程度为辅**。
- 🎭 **讲故事讲道理**：每个模式都从一个生活类比和一个真实痛点开始，不搞玄学，不背八股。
- ✅ **代码全验证**：书中所有 `python` 代码块都可以直接复制运行，并且已经通过 `scripts/verify_code.py` 全部实测通过（Python 3.12）。

## 排序方法论

每章头部都有两个星级指标：

- **难度**：★ 越多越难，从"看完就会"到"需要反复琢磨"。
- **实际使用率**：反映该模式在真实 Python 项目（Web 后端、脚本、数据分析、框架源码）中出现的频率，★ 越多越常见。

章节排序规则：**先按使用率从高到低，同使用率内按难度从低到高**。

这样安排的理由很朴素：先学**马上能用**的模式建立信心，再逐步进入**用得少但关键时刻很值钱**的模式（比如面试、源码阅读、架构设计时它们经常出现）。

## 每章结构

每一章都遵循同样的骨架，方便按图索骥：

1. **引子：先讲个故事** —— 生活类比 + 一段"坏味道"代码，让你先痛一下。
2. **模式登场** —— 定义、解决的问题、角色与结构（ASCII 类图）。
3. **Python 实现** —— 完整可运行的代码 + 运行输出。
4. **Python 特有玩法** —— 用 Python 语法糖写出的更地道版本。
5. **真实世界中的它** —— 标准库/知名框架里的真实应用。
6. **优缺点与适用场景** —— 什么时候用、什么时候千万别用。
7. **与其他模式的关系** —— 模式之间的亲戚关系。
8. **常见误区** —— 新手（和老手）最容易踩的坑。
9. **练习题** —— 附答案，答案同样是可运行的代码。
10. **小结与口诀** —— 一句话记住这个模式。

> 例外：**附录 A（速查表）** 不是模式章节，是全书 24 章的"场景→模式"检索表 + 决策树 + 面试题，供复习速览用。

## 环境要求与代码验证

- Python **3.8+**（书中代码在 Python 3.12 上全部实测通过；个别章节使用了 3.9+ 才有的语法，会在该处注明）。
- 只用**标准库**，无需 `pip install` 任何东西。
- 书中每个 `python` 代码块都**完整、自包含、可直接运行**，运行后会在终端打印出关键输出。

想自己验证全书代码？一条命令搞定：

```bash
cd python-design-patterns-book
python scripts/verify_code.py            # 验证全部章节：每个代码块都实际运行
python scripts/verify_code.py --list     # 只看统计
python scripts/verify_code.py --files "03-策略模式-Strategy.md"   # 验证单个章节
```

验证脚本会提取所有 Markdown 中的 `python` 代码块，在**隔离的临时目录**中逐个运行，任何一个代码块报错都会明确报告章节与错误信息。

书中还附带两个辅助检查脚本：

```bash
python scripts/check_outputs.py          # 核对每个代码块后的"运行输出："标注与实际输出一致
python scripts/check_consistency.py      # 核对章节编号、星级评级、目录链接、小节结构完整
```

**随书源码**：想直接跑书中的示例？`随书源码/` 目录里是全部 339 个代码示例（按章节归档、与书中逐字一致、可独立运行），重新导出与批量验证：

```bash
python scripts/export_src.py             # 从 Markdown 重新导出随书源码
python scripts/verify_src.py             # 验证随书源码里所有文件都能运行
```
